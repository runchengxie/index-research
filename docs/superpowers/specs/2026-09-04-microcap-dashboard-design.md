# 微盘股研究双标签页设计

## 目标

将 `index-research` 从单一指数长期回报页面扩展为双主题研究站。默认展示万得微盘股研究，第二个标签页保留现有指数与 ETF 长期回报研究，同时让微盘股研究中的年度收益、累计净值、滚动 CAGR 和滚动最大回撤可以直接在页面上查看。

## 用户与使用场景

主要使用者是项目维护者和希望复核长期指数表现的读者。页面首先回答三个问题：微盘股指数长期表现如何，收益路径和风险如何，历史结果有多少能够由真实交易复制。读者还应能快速切回现有的综合指数研究，不必在两个项目之间跳转。

## 数据口径

### 可直接由 Tushare 支持的部分

15,000 积分可以支持股票日线、每日指标、股票基础信息、名称变更、普通指数日线、指数成分和权重，以及 ETF 行情和复权因子等常规数据。相关最低门槛和接口说明以 Tushare 官方文档为准：

- `daily`：A 股日线行情
- `daily_basic`：每日市值、换手率和估值等指标
- `stock_basic`、`namechange`：股票基础信息和名称变更
- `index_basic`、`index_daily`、`index_weight`：指数目录、日线和成分权重
- `fund_daily`、`fund_adj`：ETF 行情和复权因子

Tushare 不直接提供 Wind 微盘股指数 `8841431.WI` 的官方历史序列。项目需要把数据分成三类并在页面明确标注：

1. Wind 或公开资料提供的原始微盘序列，作为外部参考口径。
2. 根据 Tushare 股票数据重建的微盘序列，作为可复现研究口径。
3. ETF 复权价或其他可投资产品净值，作为投资者回报代理。

重建结果不能默认等同于 Wind 原指数。股票池、ST 和退市处理、总市值字段、涨跌停、停牌、调仓价格和历史数据修订都可能产生差异。

### 首期数据范围

首期页面优先使用已经整理的公开资料和本地可验证数据，覆盖 2000–2025 年年度收益、累计净值、滚动 3/5/10/15/20 年 CAGR，以及截至 2025 年底的滚动最大回撤。若完整日线重建尚未通过校验，页面将月频最大回撤标为月频结果，并单独说明它可能低估日内和日间回撤。

## 页面结构

页面使用顶层标签页，采用 URL hash 保持静态 GitHub Pages 兼容：

- `#microcap`：默认的微盘股研究
- `#indices`：现有指数长期回报研究

顶层导航只承担主题切换。每个主题内部仍保留原来的研究口径锚点和深色模式按钮。

### 微盘股研究页

从上到下安排为：

1. 标题、数据日期和口径标签。
2. 关键指标卡：历史累计净值、长期 CAGR、最近年度收益、最大回撤。
3. 累计净值曲线：展示累计净值随时间的变化，并标注使用的序列来源。
4. 年度收益柱状图：正负收益使用不同颜色，支持悬停查看年份和收益率。
5. 滚动 CAGR 图：同时展示 3/5/10/15/20 年滚动年化收益，避免只展示一个终点数字。
6. 滚动最大回撤图：单独展示各窗口的回撤路径或终点比较，区分月频和日频口径。
7. 分阶段表现：早期黑暗时代、2006–2015、2016–2018、2019–2025 等阶段摘要。
8. 复制难度和数据边界：说明换手、流动性、冲击成本、涨跌停、停牌、回溯历史和容量限制。
9. 数据来源与下一步研究：链接到专题说明文档和原始数据说明。

### 指数长期回报页

保留当前 `site/index.html` 的指数价格回报、ETF 复权回报、接口覆盖和阅读提示，不改变现有 CSV 读取口径。页面代码拆成主题渲染函数，确保旧页面的静态快照不因新增微盘数据而失效。

## 数据产物与更新

新增公开快照建议放在：

- `outputs/microcap/summary.json`：页面摘要、日期和口径说明
- `outputs/microcap/annual_returns.csv`：年度收益和累计净值
- `outputs/microcap/rolling_cagr.csv`：滚动 CAGR
- `outputs/microcap/rolling_drawdown.csv`：滚动最大回撤
- `outputs/microcap/nav.csv`：用于绘制累计净值的时间序列
- `outputs/microcap/source_notes.json`：来源、覆盖期和限制

页面构建时把这些文件复制到 `site/outputs/microcap/`。本地优先使用 `~/data/index-research/` 或现有市场数据缓存生成结果，GitHub Actions 只补缺失日期和公开快照，不在每日任务中全量重建多年历史。

## 失败处理与信任提示

- 微盘数据文件缺失时，微盘页显示明确的来源或构建失败提示，指数研究页仍可正常使用。
- 数据日期、覆盖起止日和回报口径在页面标题或来源卡中可见。
- 月频最大回撤不能冒充日频最大回撤，图表标题和说明必须区分。
- Tushare 重建序列不能直接标为 Wind 指数，除非完成逐日或逐月校准并记录差异。

## 测试与验收

- 为数据生成函数增加年度收益、累计净值、CAGR 和最大回撤的固定样例测试。
- 为页面增加标签切换、微盘数据加载、旧指数数据加载和缺失数据提示测试。
- 执行 Python 单元测试、脚本语法检查、`git diff --check` 和绝对路径及凭证扫描。
- 用本地静态服务器打开两个 hash 页面，确认刷新后仍能进入正确标签，图表和表格均能加载。
- 生产构建后检查 GitHub Pages 的两个标签、来源说明和数据文件 HTTP 状态。
